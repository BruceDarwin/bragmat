# Bragmat App Context

Bragmat is a Flutter mobile app for recording barramundi catches in the Top End Barra Series.

Main features:
- Competitor login
- Upload fish/bragmat photos
- Enter fish length
- Convert size to points
- Best 5 fish count toward score
- Leaderboard by competition/round

Backend:
- Firebase / Firestore
- Firebase Storage for photos
- Firebase Auth if enabled

Important:
- Prefer simple Flutter/Dart code.
- Keep code beginner-friendly.
- Do not make major architectural changes without explaining them first.
